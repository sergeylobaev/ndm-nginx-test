## Задача 
Приложение должно получить в X-Forwarded-For IP пользователя и всех nginx цепочки, но не должно доверять X-Forwarded-For, который подделал пользователь. Запрос от пользователя может прийти на любой из nginx.

## Идея решения
Каждый nginx одновременно бывает и крайним (получает запрос напрямую от пользователя), и промежуточным (получает от другого nginx). Отличаем их по IP соединения:
- запрос от доверенного nginx  -> продлеваем цепочку + дописываем свой IP
- запрос от пользователя -> отбрасываем его XFF и начинаем заново

Стенд из трёх nginx в режиме обратного прокси и приложения за ними.

## Запуск стенда
```
docker compose up -d
```

## Протокол тестирования
1. Прямое обращение к приложению (без nginx)
```
curl http://localhost:8080
```
2. Через nginx3 -> app
```
curl http://localhost:8083
```
3. Через nginx2 -> nginx3 -> app
```
curl http://localhost:8082
```
4. Через полную цепочку: nginx1 -> nginx2 -> nginx3 -> app
```
curl http://localhost:8081
```
Результат, где первый IP — реальный IP клиента
```
  "headers": {
    "x-forwarded-for": "172.30.0.1, 172.30.0.11, 172.30.0.12, 172.30.0.13",
    ...
  },
```
5. Тест на защиту от спуфинга
```
curl -H "X-Forwarded-For: 1.2.3.4, 5.6.7.8" http://localhost:8081
```
Результат, фейковые адреса были удалены:
```
"headers": {
    "x-forwarded-for": "172.30.0.1, 172.30.0.11, 172.30.0.12, 172.30.0.13",
    ...
  },
```
